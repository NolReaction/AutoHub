# AutoHub — личный гараж на Android

Учебное Android-приложение для хранения автомобилей и развития системы учёта расходов, заправок и обслуживания. Проект написан автором самостоятельно, без генерации кода ИИ: основной акцент — на базе приложения, разделении ответственности и локальных данных.

**Статус:** развивающийся учебный проект. Готовы основные операции с гаражом; подсистема автомобильных расходов пока представлена основой в слое данных.

## Что реализовано

- Список автомобилей, добавление, редактирование, удаление и избранное.
- Карточки автомобилей и диалог с их данными.
- Локальное хранение в Room и наблюдение за изменениями через Flow/StateFlow.
- Навигация между гаражом, формой автомобиля и меню.
- Светлая/тёмная тема с сохранением настройки в Preferences DataStore.
- Переключение языка приложения: русский и английский.
- Начальные демонстрационные автомобили при пустой базе.

## Технологии и устройство

Kotlin, Jetpack Compose, Material 3, Navigation Compose, ViewModel, Coroutines/Flow, Room, KSP, Hilt и Preferences DataStore. Версии зависимостей закреплены в [каталоге Gradle](gradle/libs.versions.toml).

Экран получает состояние из ViewModel; ViewModel обращается к репозиторию, а репозиторий — к Room DAO. Зависимости базы и настроек предоставляет Hilt. Модели интерфейса отделены от сущностей базы данных.

| Часть | Где смотреть |
| --- | --- |
| Точка входа и навигация | [MyGarageApp.kt](app/src/main/java/com/dima/mygarage/ui/MyGarageApp.kt) |
| Экран гаража, состояние и формы | [ui/garage](app/src/main/java/com/dima/mygarage/ui/garage) |
| Репозитории | [data/repository](app/src/main/java/com/dima/mygarage/data/repository) |
| Room: база, сущности, DAO и конвертеры | [data/local](app/src/main/java/com/dima/mygarage/data/local) |
| Внедрение зависимостей | [data/di](app/src/main/java/com/dima/mygarage/data/di) |
| Настройки | [data/settings](app/src/main/java/com/dima/mygarage/data/settings) |

Для расходов, топлива и обслуживания созданы сущности, DAO и репозитории. Это задел для следующих функций: законченного пользовательского сценария учёта расходов и отдельного экрана подробной статистики в текущей версии ещё нет.

## Запуск

1. Открыть корень проекта в Android Studio с поддержкой Android Gradle Plugin 9.2.
2. Установить Android SDK 36.1. Для Gradle в [конфигурации проекта](gradle/gradle-daemon-jvm.properties) указан JDK 21.
3. Выполнить Gradle Sync и запустить конфигурацию `app` на устройстве или эмуляторе Android 7.0 / API 24 либо новее.

Сборка debug APK из корня проекта:

```bash
./gradlew :app:assembleDebug
```

В Windows используется `gradlew.bat`. Результат сборки — `app/build/outputs/apk/debug/app-debug.apk`.

## Границы проекта

AutoHub показывает самостоятельную практику современной Android-разработки и построения локального слоя данных. Серверная синхронизация и опубликованный релиз здесь не заявлены. В репозитории есть стартовые примеры unit- и instrumented-тестов; они не являются покрытием всех пользовательских сценариев.
